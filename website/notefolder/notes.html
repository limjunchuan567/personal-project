Week 1

C Fundamentals & Terminal Commands

Key Terminal Commands

In C, you write your code in a file, compile it into a computer program, and run it directly in the terminal:

code hello.c # Create or edit a source code file make hello # Compile hello.c into a runnable program (named hello) ./hello # Run your compiled program ls # List all files in the current folder cd # Change directory into another folder mkdir # Make a new folder rm # Delete a file
Basic Structure of a C Program

Every C program begins running from the main(void) function. Headers at the top give you access to helper functions:

#include <stdio.h> // Standard Input/Output library (for printf) #include <cs50.h> // CS50 Library (for get_string, get_int) int main(void) { string name = get_string("What is your name? "); printf("Hello, %s\n", name); return 0; }
Format Specifiers (Placeholders in printf)
SpecifierData TypeExample Usage
%sString (text)printf("%s\n", name);
%i or %dInteger (whole number)printf("Score: %i\n", score);
%cSingle characterprintf("Grade: %c\n", 'A');
%fFloat (decimal number)printf("%.2f\n", price); // 2 decimals
%liLong integerprintf("Big number: %li\n", big_num);
Conditionals, Loops & Functions
  • Conditionals (if/else): if (x < y) { ... } else if (x > y) { ... } else { ... }
  • Logical Operators: && (and), || (or), ! (not), == (equals).
  • Loops: while (condition), for (int i = 0; i < n; i++). If you get stuck in an infinite loop, press Ctrl + C to exit.
  • Custom Functions: Always write a prototype signature at the top of the file so C knows your function exists before main() is called.
Week 2

How Compiling Works, Arrays & Memory

The 4 Steps of Compiling

When you run make program, the computer does four things in order:

1. Preprocessing
Pastes full code for every #include.
2. Compiling
Translates C code into assembly language.
3. Assembling
Converts assembly into binary (0s and 1s).
4. Linking
Merges your binary with library code into 1 file.
Arrays & Memory Sizes

An array stores items of the same type back-to-back in memory, starting at index 0:

int scores[3] = {85, 92, 78}; // Divide by 3.0 (float) so decimals aren't accidentally cut off! float average = (scores[0] + scores[1] + scores[2]) / 3.0;
How Strings Work in C (The Null Terminator)

A string in C is just an array of characters ending with a hidden zero byte called the null character ('\0'):

Memory view of "HI!":
['H'] ['I'] ['!'] ['\0'] → It has 3 letters, but takes up 4 bytes in memory!
Command-Line Arguments: argc & argv
int main(int argc, string argv[]) { // argc: count of arguments entered // argv: array of strings entered (argv[0] is the program name) if (argc != 2) { printf("Usage: ./program <name>\n"); return 1; // Error code } printf("Hello, %s\n", argv[1]); return 0; // Success }
Week 3

Algorithms, Big-O Notation & Recursion

Big-O Notation Made Simple
  • $O$ (Big-O): The worst-case running time (how long it takes at most).
  • $\Omega$ (Big-Omega): The best-case running time (how long it takes when lucky).
  • $\Theta$ (Big-Theta): Used when best-case and worst-case are the exact same.
Search and Sort Comparison
AlgorithmBest CaseWorst CaseHow It Works
Linear Search$\Omega(1)$$O(n)$Checks items one by one from beginning to end.
Binary Search$\Omega(1)$$O(\log n)$Splits sorted list in half each step. (List must be sorted!)
Selection Sort$\Omega(n^2)$$O(n^2)$Finds smallest item, moves it to front, repeats.
Bubble Sort$\Omega(n)$$O(n^2)$Repeatedly swaps adjacent items that are out of order.
Merge Sort$\Omega(n \log n)$$O(n \log n)$Recursively splits array in half and merges sorted halves.
Custom Data Types (typedef struct)

Allows you to bundle related variables together under one new type:

typedef struct { string name; string phone; } person; person people[2]; people[0].name = "Jacob"; people[0].phone = "+65-8888-0000";
Recursion: Functions Calling Themselves

A recursive function must have two ingredients to work without crashing:

  1. Base Case: The stopping condition where it returns without calling itself.
  2. Recursive Case: The step where it calls itself with a simpler problem.
Week 4

Pointers, Dynamic Memory (malloc & free) & Files

What is a Pointer?

A pointer is simply a variable that stores a memory address (where something lives in RAM):

  • & operator: Gives you the address of a variable (e.g. &x).
  • * operator: "Go to this address" (dereferences the pointer to read or change the value).
Dynamic Memory: malloc and free
// Ask the computer for memory to store 3 numbers int *list = malloc(3 * sizeof(int)); if (list == NULL) { return 1; // Out of memory check } list[0] = 10; list[1] = 20; list[2] = 30; // ALWAYS free memory when you're done with it! free(list);
Memory Layout (Heap vs Stack)
Machine Code
Compiled binary code.
Globals
Global variables.
Heap (malloc)
Grows downwards.
Stack (Local vars)
Grows upwards.
Reading and Writing Files in C
FILE *file = fopen("data.txt", "w"); // "r" = read, "w" = write, "a" = append if (file == NULL) { return 1; // File error } fprintf(file, "Hello from C!\n"); fclose(file); // Always close files when done!

Week 6

Python Basics & Differences from C

Key Differences Between C and Python
  • No Compiling Needed: Python runs scripts line by line (python hello.py).
  • No Type Declarations: You just write x = 5 instead of int x = 5;.
  • Automatic Memory: No need to use malloc or free. Python manages memory automatically.
Python Data Types & Collections
# List: flexible, changeable sequence scores = [85, 92, 78] scores.append(95) # Tuple: fixed, unchangeable sequence coords = (1.3521, 103.8198) # Dictionary: key-value pairs (like a phonebook) person = { "name": "Jacob", "role": "ETPS Scholar", "languages": ["C", "Python", "SQL"] } # Set: unique items only (removes duplicates automatically) tags = {"math", "science", "math"} # {"math", "science"}
Safe Input & Handling Errors
try: x = int(input("Enter a number: ")) print(f"Squared: {x ** 2}") except ValueError: print("Please enter a valid number!")

Joining Multiple Tables with JOIN
SELECT shows.title, ratings.rating FROM shows JOIN ratings ON shows.id = ratings.show_id WHERE ratings.rating >= 9.0 ORDER BY ratings.rating DESC LIMIT 10;
