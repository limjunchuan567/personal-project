WK 01

C Fundamentals & Terminal Architecture

Key Terminal Commands & Workflow

In C development, the workflow begins with writing source code, compiling into machine-executable binary, and executing from the terminal:

code hello.c # Create or edit source file make hello # Compile hello.c into executable 'hello' (clang/gcc behind the scenes) ./hello # Execute the compiled binary in the current directory ls # List files in current directory cd # Change directory mkdir # Create a new directory rm # Remove a file
Source Code Structure & Standard Headers

Every C program enters through main(void). Standard headers provide pre-written prototypes:

#include <stdio.h> // Standard Input/Output (printf) #include <cs50.h> // CS50 Library (get_string, get_int, etc.) int main(void) { string name = get_string("What is your name? "); printf("Hello, %s\n", name); return 0; }

Conditionals, Loops & Functions
  • Conditionals: if (x < y) { ... } else if (x > y) { ... } else { ... }
  • Logical Operators: && (AND), || (OR), ! (NOT), == (Equality).
  • Loops: while (condition), for (int i = 0; i < n; i++). Exit infinite loops using Ctrl + C.
  • Function Prototypes: Always declare function signatures above main() so the compiler recognizes them.
WK 02

Compilation Pipeline, Arrays & Memory Footprint

The 4-Stage Compilation Pipeline

When you run make program, the compiler executes four distinct transformations:

1. Preprocessing
Replaces #include with full header code.
2. Compiling
Converts C code into assembly instructions.
3. Assembling
Translates assembly into binary machine code (0s & 1s).
4. Linking
Merges compiled code with library binaries into executable.
Arrays & Contiguous Memory

Arrays store values back-to-back in continuous memory bytes using zero-based indexing:

int scores[3] = {85, 92, 78}; // Always cast to float or use 3.0 to prevent integer truncation! float average = (scores[0] + scores[1] + scores[2]) / 3.0;
Strings as Null-Terminated Arrays

A string in C is simply an array of char values terminated by the invisible null character '\0' (ASCII 0):

Memory Layout of "HI!":
['H' (72)] ['I' (73)] ['!' (33)] ['\0' (0)] → Length is 3 characters, but occupies 4 bytes in memory!
Command-Line Arguments: argc & argv
int main(int argc, string argv[]) { // argc: argument count (includes program name itself) // argv: array of strings containing arguments if (argc != 2) { printf("Usage: ./program <name>\n"); return 1; // Non-zero indicates exit failure } printf("Hello, %s\n", argv[1]); return 0; // 0 indicates clean exit }
WK 03

Algorithms, Asymptotic Complexity & Recursion

Asymptotic Complexity Notation
  • $O$ (Big-O): Upper bound / worst-case running time.
  • $\Omega$ (Big-Omega): Lower bound / best-case running time.
  • $\Theta$ (Big-Theta): Exact bound when best-case and worst-case are identical.
Algorithm Comparison Matrix
AlgorithmBest Case ($\Omega$)Worst Case ($O$)Core Mechanism
Linear Search$\Omega(1)$$O(n)$Iterates sequentially one-by-one from index 0.
Binary Search$\Omega(1)$$O(\log n)$Halves search space repeatedly. Requires sorted data!
Selection Sort$\Omega(n^2)$$O(n^2)$Scans for smallest element and places it in sorted portion.
Bubble Sort$\Omega(n)$$O(n^2)$Swaps adjacent pairs; terminates early if no swaps occurred.
Merge Sort$\Omega(n \log n)$$O(n \log n)$Recursively divides array into halves and merges sorted sub-arrays.
Custom Data Types: typedef struct
typedef struct { string name; string phone; } person; person people[2]; people[0].name = "Jacob"; people[0].phone = "+65-8888-0000";
Recursion Architecture

A recursive function must always satisfy two criteria to prevent stack overflows:

  1. Base Case: Stopping condition that returns without calling itself.
  2. Recursive Case: Calling itself with a reduced sub-problem.
WK 04

Pointers, Dynamic Memory (malloc/free) & Memory Safety

Hexadecimal & Memory Addresses

Hexadecimal (Base-16: 0-9 and A-F) represents byte values succinctly. Addresses are prefixed with 0x.

  • & operator: Extracts the memory address of a variable (e.g. &x).
  • * operator: Dereferences a pointer, accessing the value stored at that address (e.g. *p).
Dynamic Memory Allocation: malloc & free
// Allocate heap memory for 3 integers int *list = malloc(3 * sizeof(int)); if (list == NULL) { return 1; // Out of memory check! } list[0] = 10; list[1] = 20; list[2] = 30; // ALWAYS free dynamically allocated memory to avoid leaks! free(list);

WK 06

Python Architecture & Differences from C

C vs Python Architecture
  • Interpreted: Python executes scripts line-by-line via interpreter (python file.py), eliminating manual compilation.
  • Dynamic Typing: Variables do not require explicit type declaration (x = 42 vs int x = 42;).
  • Garbage Collected: Memory allocation and deallocation are handled automatically (no malloc/free).
Core Python Data Structures
# List: ordered, mutable sequence scores = [85, 92, 78] scores.append(95) # Tuple: ordered, immutable sequence coordinates = (1.3521, 103.8198) # Dictionary: key-value mapping (O(1) average lookup) person = { "name": "Jacob", "role": "ETPS Scholar", "skills": ["C", "Python", "SQL"] } # Set: unique values collection unique_tags = {"security", "systems", "security"} # {"security", "systems"}
Clean Loops & Safe Input Parsing
try: x = int(input("Enter integer: ")) print(f"Calculated square: {x ** 2}") except ValueError: print("Invalid input: not an integer")

Relational Queries & JOIN Operations
-- Join shows and ratings on common foreign key: SELECT shows.title, ratings.rating FROM shows JOIN ratings ON shows.id = ratings.show_id WHERE ratings.rating >= 9.0 ORDER BY ratings.rating DESC LIMIT 10;
Database Indexes: O(n) vs O(log n)

Without an index, SQLite performs a sequential table scan ($O(n)$). Creating an index constructs a B-Tree, bringing query lookup time down to $O(\log n)$:

CREATE INDEX title_index ON shows (title);
